# Plan: M1 "Switch from Pencil"

Implements milestone M1 of [PRD.md](../../PRD.md). Work is split into phases that each leave `main` green
(typecheck, lint, test).

## Phase 1: format v1 and `.pen` import (done, 2026-10-22)

1. **File migrations (M1-9).** `packages/doc/src/migrate.ts`: `DOCUMENT_VERSION`, `migrateDocument` upgrades
   any older document step by step before validation. `.pego` files and the IndexedDB autosave both go through
   it. Bump to version 1 so older Pego builds refuse v1 files instead of silently dropping new props.
2. **Schema v1 (part of M1-4, M1-7).**
   - `effects` on every node except group and ref: drop shadow / inner shadow (`color`, `x`, `y`, `blur`,
     `spread`) and layer blur (`radius`).
   - Stroke `width` per side: one value or `[top, right, bottom, left]`.
   - Text: `lineHeight` (multiplier), `letterSpacing` (px), `fontFamily` may be a `$variable`.
   - Path: optional `viewBox` so imported and SVG paths scale to the node size.
3. **Wire v1 through the stack.** Renderer, properties panel (effects, text spacing), agent JSON schemas,
   serializer, prompts, CLAUDE.md.
4. **`.pen` import (M1-1).** `packages/doc/src/pen.ts`: `importPen(json) → { doc, warnings }`, tested against
   `design/pego.pen`. File → Open accepts `.pen`; the result opens as an unsaved `.pego` document and lists
   anything that could not be converted.

Result: `design/pego.pen` imports with every instance resolving and renders like the Pencil export
(`design/png/editor.png`); the only visible difference is the font (Geist is not loaded yet, see step 11).
Not covered yet: per-corner radius (largest corner used), stroke alignment, themed variables.

## Phase 2: paints and export (done, 2026-10-22)

5. Gradient fills (linear, radial) as a paint type next to solid colors (M1-4).
6. Image fill, embedded as a data URI and scaled down to 2048 px on import (M1-5). No separate image node:
   a rectangle with an image fill covers it. Storing assets next to the file is left for later.
7. Export PNG and SVG of a frame or the selection (M1-3).
8. Export HTML/CSS of a frame: flex → flexbox, variables → CSS custom properties (M1-2).
9. Agent tool `get_code` (HTML/CSS of a node) for implementing designs from Claude Code.

Result: new `packages/export` (HTML + SVG); Fill section with solid / linear / radial / image; Export section
(PNG 1x-3x transparent, SVG, HTML). A test board with every paint and effect renders the same on the canvas,
in the exported HTML and in the exported SVG (checked side by side in Chromium).
Not covered yet: gradient/image fills on text and icons, `.pen` gradient import, gradient strokes.

## Phase 3: documents and platforms

10. Multiple pages per document (M1-6).
11. Font loading (Google Fonts) for `fontFamily` values other than Inter (M1-7).
12. Desktop builds for Linux and Windows (M1-8).
