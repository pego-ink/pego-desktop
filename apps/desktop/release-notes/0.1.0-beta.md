Pego 0.1.0-beta brings the web onto your canvas, motion and living shader backgrounds, photos and generated images, a floating interface, and installers for macOS, Windows and every major Linux distribution. Full history: [changelog.pego.ink](https://changelog.pego.ink).

## Highlights

**Motion and shaders.** Give any layer an entrance (fade, slide, grow, pop), play it on the canvas and export it as CSS animation; numbers can count up. Fill any frame or shape with an animated shader (aurora, flowing gradients, waves, film grain, shimmer, pulsing dots) or write your own.

**Images from anywhere.** Search openly licensed photos in the Assets panel (the agent can find real photos too, with credit kept on the layer), generate images from a prompt with your own Google Gemini (Nano Banana), OpenAI or other image model, or paste an image or its link from any site.

**The Pego browser extension.** Send a web page, one of its elements, or a screenshot from Chrome to your canvas as editable layers.

**Bring any website onto the canvas.** A built-in browser lives in the left rail. Open a page, pick an element, and import it as editable layers: flex rows and columns come back as auto layout, the page's fonts are used when available, remote images are embedded, and only what layers can't express becomes an image. Preview and import at iPhone, Pixel, iPad, MacBook or desktop widths. The agent can use the browser too.

**A faster canvas.** A right-click menu with Copy as SVG, PNG, React + Tailwind, HTML/CSS or JSON; Paste here and Paste to replace (⌘⇧R); Add and remove flex layout (⇧A, ⇧⌥A); Flip horizontal and vertical (⇧H, ⇧V); Hide/Show and Clip content. Selections show four corner handles, and every edge resizes along its whole length. While the agent designs, the layers it works on shimmer with a single "Generating" label. Pego Magic offers one-click ideas for any selection: a new layout, style, palette or type.

**Your interface, your way.** Settings › General › Interface › Floating turns the panels into cards over a full canvas, like pen.dev. The toolbar can sit at the bottom, top, left or right, and the agents' canvas cursors can carry names.

**Better designs from the agent.** It follows a set of polish rules on every design and checks its own work for uneven corners, thin icons, ragged rows and lopsided padding. New instrument-panel style, inspired by portable synthesizers.

**Home, projects and components.** Pego opens on Home, with your tabs restored behind it. Move a project to the Trash from Home, export it as a `.pego` file or every screen as PNG, SVG or code, or turn the open document into a project with File › Save as project. Components live in a searchable Assets panel you can drag from.

**Claude Code, closer to your work.** Copy for AI (⌘⇧C) puts a reference to the selected layers on the clipboard. Claude Code can edit any project by name in a background tab, without switching what you see.

**Settings and updates.** A settings window for the editor, the agent and models, and shortcuts. The macOS app updates itself and follows your light or dark theme.

## Install

| System                 | Download                                                                                       |
| ---------------------- | ---------------------------------------------------------------------------------------------- |
| macOS (Apple silicon)  | `Pego-0.1.0-beta-arm64.dmg`                                                                    |
| macOS (Intel)          | `Pego-0.1.0-beta-x64.dmg`                                                                      |
| Windows                | `Pego-0.1.0-beta-win-x64.exe` (`-win-arm64.exe` on Windows on ARM; `.zip` for a portable copy) |
| Debian, Ubuntu         | `sudo apt install ./Pego-0.1.0-beta-linux-<arch>.deb`                                          |
| Fedora, RHEL, openSUSE | `sudo dnf install ./Pego-0.1.0-beta-linux-<arch>.rpm`                                          |
| Arch Linux             | `sudo pacman -U Pego-0.1.0-beta-linux-<arch>.pacman`                                           |
| Any Linux              | `chmod +x Pego-0.1.0-beta-linux-<arch>.AppImage` and run it, or unpack the `.tar.gz`           |

`<arch>` is `x64` for Intel/AMD or `arm64` for ARM. Checksums are in `SHA256SUMS.txt`.

## Good to know

- **File format 7.** Documents saved by this version can't be opened by 0.0.1-beta; older files open and upgrade automatically.
- **Linked photos.** Photos found in the Assets panel are linked, not embedded, and need a connection to show.
- **Updates.** The macOS app updates itself. On Windows and Linux, install the new version over the old one.
- **Unsigned builds.** Windows and Linux builds are not code-signed yet: Windows SmartScreen may ask you to confirm ("More info" › "Run anyway").
- **The built-in browser** is part of the desktop app only.
