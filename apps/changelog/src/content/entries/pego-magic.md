Select a frame and click the ✨ button next to it. Above the prompt box, Pego Magic offers ideas you can run with one click.

- **Layout variation**: the same style with a fresh structure.
- **Style variation**: the same content in a new visual direction.
- **Color variation**: the same design with a new palette that keeps text readable.
- **Explore typography**: a new font pairing and type scale.
- **Surprise me**: a bold take on the same idea.
- **Export HTML**: the selection as HTML and CSS, ready to copy.

Each idea is built as a copy next to the original, so you can compare the two and keep what you like. Your original is never touched. The This chat / New chat switch still decides where the run goes.
