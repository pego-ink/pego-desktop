---
title: Save from the close tab dialog
date: 2026-10-24T10:00:00Z
summary: Closing a tab with unsaved changes now offers Save, so you can keep your work without cancelling first.
tags: [improved]
---

When you close a tab that has unsaved changes, the confirmation now has three choices: Cancel, Don't save, and Save. Save writes the document and then closes the tab. For a new document it opens the Save As dialog first, and if you cancel it the tab stays open with your work intact.
