---
title: The agent can place SVG files from your design folder
date: 2026-10-24T12:00:00Z
summary: Ask the agent to place the SVG files from a folder in your project's design folder and it reads and imports them as editable layers.
tags: [new]
---

Tell the agent which folder in your project's design folder to use, for example "place the SVGs in design/logo/pigeon on the canvas", and it lists the SVG files there, reads them and adds each one as editable vector layers. This works for the agent panel and for Claude Code in a terminal.

The agent can only read SVG files inside the design folder. It cannot read other files on your computer, and it cannot change or delete any files this way.
