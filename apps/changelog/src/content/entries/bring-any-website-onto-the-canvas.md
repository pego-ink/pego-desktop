The desktop app now has a browser. Open the Browser panel in the left rail, type an address, and bring what you see onto the canvas.

- Take a screenshot of the page, or import the whole page as layers.
- Use the element picker to import a single section, a card or a button.
- Pick a device to preview and import at that width: iPhone, Pixel, iPad, MacBook or a desktop size.

## Layers you can edit

Imports are rebuilt as real layers, not a flat picture.

- Rows and columns come across as auto layout, with the page's gap and padding.
- Text keeps the page's fonts when they are available.
- Remote images are embedded in the file, so the design still opens offline.
- Pego falls back to a pixel-exact image only for the parts layers can't express.

## The agent can browse too

Ask the agent to open a page, import a section of it, or look at screenshots while it designs. It uses the same browser you do.
