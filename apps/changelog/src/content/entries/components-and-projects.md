## Assets panel

Your components now live in one panel, grouped by page, with live thumbnails and search. Drag a component onto the canvas, or press **+** to place it. Every card works from the keyboard too: Enter shows the component, Shift+Enter inserts it.

## Save as project

**File › Save as project** turns the document you are looking at into a new project. If it wasn't saved to a file yet, the chat that built it comes along.

## Copy for AI

Select layers and press **⌘⇧C** to copy a short reference to them: the project, the file and the layers. Paste it into Claude Code or another assistant so it knows exactly what you mean.

## Claude Code works on any project

Ask Claude Code to change a project by name and it edits that project in a background tab, without switching what you see. If the project's file can't be read, it stops and tells you instead of starting from an empty design.
